Hugging Face Prompt Latency Tester

Sends a parent prompt as the system message and a child prompt as the user message to the Hugging Face chat-completions API. The timer starts when you press Send and stops after the complete response has arrived and been read.

For local testing only. Your access token is kept in this page's memory and sent directly to Hugging Face. Do not publish this file with a token or use a production token in a client-side app.
